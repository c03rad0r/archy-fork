# Skill routing

Load `archipelago-app` for manifests, containers, app previews, lifecycle,
credentials, signer integration, or app packaging. Load `archipelago-design` for
any newly authored or changed UI. For backend-only work, use only the system
skill and the relevant project docs.

Planning stays planning. A source change, node mutation, deployment, or
publication requires that explicit scope from the user. A skill supplies
workflow knowledge; it does not grant additional privileges.
